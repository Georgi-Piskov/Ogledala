# Залата на огледалата

Интерактивна карта за една D&D сесия: дворцова зала с невидими убийци, които партито търси с огледала и свещници.

- Екран за играчите: https://georgi-piskov.github.io/Ogledala/
- Екранът на Водещия е същият адрес с личен ключ накрая (`#dm=...`). Ключът не се пази в това репо.

Страницата е един файл (`index.html`) без сървър. Екраните се свързват през публични MQTT релета; играта се пази в браузъра на Водещия и като запазено съобщение на релетата.

## Чужди материали

- Подложка „Imperial Grand Hall“ — Ori the Cartographer (безплатната версия с подпис)
- `vendor/mqtt.min.js` — MQTT.js (MIT)
